title: Cannot Find Documentation Page
description: Quick fix for missing docs in Newby Enteprises.
---

## Symptoms

- A page returns "Not Found"
- Documentation link is broken

## Possible Causes

- Page was deleted or renamed
- Incorrect URL

## Quick Fix

<Steps>
  <Step title="Check page list">
    Go to your project dashboard and review the page list for similar titles.
  </Step>
  <Step title="Restore from trash">
    Go to the Trash section. Pages deleted in the last 30 days can be restored.
  </Step>
  <Step title="Correct URL">
    Double-check the URL for typos or spaces.
  </Step>
</Steps>
