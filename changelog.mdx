## Upgrading to the Latest Version

Follow these steps to ensure your documentation space uses the newest features.

<Steps>
  <Step title="Backup Your Data" icon="database">

  Export all projects:

  ```bash
  npx newby-export --all-projects > backup.json
  ```

  </Step>
  <Step title="Update CLI" icon="download">

  <CodeGroup tabs="npm,yarn">
  ````bash
  npm install -g @newby/cli@latest
  ````
  ````bash
  yarn global add @newby/cli@latest
  ````
  </CodeGroup>

  </Step>
  <Step title="Rebuild Site" icon="rocket">

  ```bash
  newby rebuild --prod
  newby deploy
  ```

  Verify at `https://docs.example.com`.

  </Step>
</Steps>
