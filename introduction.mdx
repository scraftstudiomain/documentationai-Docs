## Overview

Newby Enterprises empowers you to organize, manage, and collaborate on project documentation effortlessly. You create structured spaces for all your docs, from technical specs to user guides, with powerful search, version control, and real-time collaboration features. Teams use it to centralize knowledge, reduce silos, and streamline workflows.

Whether you manage software projects, marketing campaigns, or internal wikis, Newby Enterprises scales with your needs. Customize hierarchies, embed media, and integrate with tools like GitHub or Slack.

## Get Started Quickly

Follow these steps to set up your first documentation space.

<Steps>
  <Step title="Sign Up" icon="user-plus">
    Visit `https://app.newbyenterprises.com` and create a free account with your email.
  </Step>
  <Step title="Create a Space" icon="plus">
    Click **New Space** and name it, like "Project Alpha Docs".
  </Step>
  <Step title="Add Your First Doc" icon="file-text">
    Upload Markdown files or write directly in the editor.
  </Step>
  <Step title="Invite Team" icon="mail">
    Share the space link or add members via email.
  </Step>
</Steps>

<Callout kind="tip">
  Pro tip: Use keyboard shortcuts like <kbd>Ctrl</kbd>+<kbd>K</kbd> for quick search once inside your space.
</Callout>

## Quick Integration Example

Embed Newby Enterprises docs in your apps using our API.

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  const response = await fetch('https://api.example.com/v1/spaces/{spaceId}/docs', {
    headers: {
      'Authorization': `Bearer ${YOUR_API_KEY}`
    }
  });
  const docs = await response.json();
  console.log(docs);
  ```
  ```python
  import requests

  headers = {'Authorization': f'Bearer {YOUR_API_KEY}'}
  response = requests.get('https://api.example.com/v1/spaces/{spaceId}/docs', headers=headers)
  docs = response.json()
  print(docs)
  ```
</CodeGroup>
